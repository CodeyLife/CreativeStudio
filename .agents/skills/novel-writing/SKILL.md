# 中文长篇创作方法论（工程化 × 文学质量）

## 两副眼镜

1. **工程化眼镜**：把一部百万字长篇小说当成可持续交付的长期项目来管理——
   设计先行、分层规划、场景清单、一致性账本、修订循环、质量门、连载节奏管理。
   它回答"怎么保证写得到结尾、不烂尾、不崩设定、不改大纲"。
2. **文学质量眼镜**：回答"读者凭什么读下去、为什么被打动、为什么记得住"——
   读者承诺、人物欲望与代价、关系与群像、世界观压力、语言声音、节奏与留白。

两条线互相约束：工程化提供结构骨架与回滚能力，文学质量决定每句话的价值。
任何决策都应同时过这两关。

## 使用方式

- 需要在开工前把创意变成可执行计划 → 走 **工程化流程**（[METHOD.md](METHOD.md)）。
- 需要把某章、某个人物、某段关系、某个世界观写到位 → 查 **文学质量维度**
  （[CRAFT.md](CRAFT.md)）。
- 需要评判一部已完成稿或半成品 → 用 **审校矩阵**（CRAFT.md §12）+ 工程化质量门
  （METHOD.md §6）。
- 需要找原始方法与证据来源 → [REFERENCES.md](REFERENCES.md)。
- 需要把外部资料或优秀作品转成提示词/规则 → 先走 **资料转化协议**，只吸收机制，
  不吸收可识别文风、角色、情节或单一平台偏好。

## 核心原则（每次创作/审校都先过一遍）

1. **先定读者承诺，再定事件规模。** 读者期待一组可持续兑现的体验，不是世界观名词堆。
2. **主题不是口号，是选择压力。** 主题必须进入人物在利益、关系、责任、代价间的具体选择。
3. **最小动力 = 欲望遇阻力产生选择。** 没有选择，事件只是搬运；没有代价，转折没有重量。
4. **每一层大纲都回答：谁想要什么、什么阻止他、他怎么选、选后改变了什么。**
5. **大纲给方向与边界，不把正文锁成待办清单。** 冻结因果、状态、功能，留现场发现空间。
6. **人物是持续做决定的人。** 背景只有产生可观察后果时才有效。
7. **配角有离开主角也成立的欲望、关系、秘密、工作和代价。**
8. **感情线靠行动、物件、习惯、误解、牺牲与共同承担累积；心理总结不能代替发生。**
9. **世界观是压力系统。** 规则、制度、资源、阶层、地理真实改变人物的可选集合。
10. **文笔服务于视角与情绪。** 最合适的语言是"此刻只能这样说"的语言。
11. **节奏是张弛与回报的分布，不是每章加速。** 行动、高潮、余波、相处、恢复、内省都成立。
12. **留白必须有证据可推断。** 留白不是省略因果，也不是用模糊代替具体。
13. **长篇要管理疲劳。** 反复的冲突、升级、误会、反转和意象必须改变层级、意义或代价。
14. **质量判断回到证据与回归。** 分数只指示问题；必须看正文、状态变化、事实和跨场景结果。

## 资料转化协议

外部资料、获奖作品、榜单作品、作家访谈和开源工作流进入本 skill 前，必须先转成可迁移的
创作机制。成功信号只说明"值得细读"，不直接说明"应该模仿"。

1. **先判证据类型**：奖项/榜单/传播度 = 影响力信号；创作谈 = 作者自述；研究论文 =
   抽象模型；作品细读 = 机制假设；开源项目 = 流程/数据结构参考。
2. **再抽共享机制**：把材料改写为"在什么输入类别中，什么机制解决什么失败类"。
   例如不是"学某作品的克系设定"，而是"异质设定要同时约束知识边界、社会制度、
   人物风险与阶段回报"。
3. **落到执行点**：每条机制至少进入一处产物：创作契约、人物/世界规则、章节蓝图、
   场景计划、审校证据、学习候选或回归用例。
4. **写明边界**：说明它不覆盖哪些题材、章节功能、叙述视角或读者承诺，避免把局部经验
   固化成全局硬门。
5. **双样本验证**：用原失败场景 + 一个题材/关系/章节功能明显不同的样本验证；只提升单个
   benchmark、榜单相似度或模型评分不算通过。

## 优秀作品参照法

参照作品只提供"可检验的 craft 问题"，不得输出仿写任务。

| 参照方向 | 可学习的问题 | 禁止转化成 |
| --- | --- | --- |
| 现实主义长篇（如《平凡的世界》《人世间》） | 时代、阶层、职业、家庭制度如何改变人物可选集合 | 所有作品都要现实题材或宏大篇幅 |
| 普通人叙事（如《活着》《许三观卖血记》） | 叙述声音如何贴合人物知识、生活经验和苦难承受方式 | 悲剧口吻、第一人称或苦难强度模板 |
| 科幻/幻想（如《三体》《我们生活在南京》） | 核心假设如何推演出社会后果，并反压人物选择 | 术语堆砌、尺度竞赛或冷酷感模板 |
| 历史/考据型故事（如《长安的荔枝》） | 资料如何变成地理、制度、技术、人情的连续阻碍 | 把考据数量、倒计时或官场话术当质量 |
| 精品网文（如《诡秘之主》《全职高手》） | 长线问题、阶段回报、群像职业/身份系统如何维持连载动力 | 榜单热度、爽点密度、升级节拍硬指标 |
| 群像/江湖/仙侠（如《天之下》《剑来》） | 配角弧光、关系网络、意象回声如何累积长期意义 | 慢热、哲思、支线数量或专有名词负担 |

## 阶段最佳指引

1. **立项/大纲**：先写读者承诺、主题问题、主角欲望/缺口、核心对抗、世界压力和结局包络；
   未能改变人物选择的设定先不进入正文。
2. **分卷/剧情线**：每个弧必须有局部承诺、阶段对抗、不可逆变化、伏笔窗口、余波出口；
   允许安静弧，但要有状态、关系、理解、资源或注意力变化。
3. **章节蓝图**：锁定功能、POV、起止状态、信息释放、行动成本、情绪余波；不要把蓝图写成
   正文逐句提纲。
4. **正文生成**：让读者经历可观察过程：注意到什么、想要什么、受阻于什么、如何判断、
   做出什么动作、承担什么结果。
5. **审校/修订**：按根因分层定位：事实/因果、场景承载、人物动力、POV/声部、句法、
   词语；只修问题层，保护有效段落。
6. **学习沉淀**：只有当问题具备可复用机制、受影响输入类和边界时，才沉淀为 skill 候选；
   个案偏好、单章指标和作品风格相似度不得升级为规则。

## 铁律

- **禁止把文学偏好变成硬性检查表。** 安静章、余波章、无幽默、无感情推进都合法，只要功能有可感知证据。
- **禁止精确短语黑名单 / 逐句模板。** "AI 味"、同质化等问题要在机制层解决，不在词表层堵。
- **修订按根因分层**：事实/因果 → 场景承载 → POV/声部 → 句法 → 词语。只修问题层，保护未受损部分。
- **每次改动都回归**：原失败案例 + 至少一个题材/关系/功能明显不同的反例。
- **正例是机制示意，不是逐句仿造模板；反例是失败类别，不是精确词黑名单。**
