# 文学创作质量：五个维度与成文技法

> 五个质量维度（D1 世界观 / D2 故事性 / D3 群像 / D4 感情线 / D5 幽默与语言体验）
> 是判断的锚点，不是每章必须逐项满足的检查表。判断重点是"功能是否有可感知证据"，
> 而不是事件数量、是否推进恋爱、是否有笑点。

## 1. D1 世界观：规则、制度、日常与主题

### 1.1 五层

1. **物理/超自然规则**：什么能发生、什么不能、代价是什么。
2. **资源与技术**：力量、信息、交通、医疗、货币、生产、传播如何分配。
3. **制度与组织**：家庭、门派、官府、公司、宗教、学校、军队、平台如何运作。
4. **文化与日常**：语言、礼仪、食物、节庆、职业、禁忌、审美、地方差异。
5. **价值与冲突**：世界奖励什么、惩罚什么、对谁不公平。

只有第一层是"力量设定"；只有文化名物是"装饰性考据"。

### 1.2 规则可内化三问

- 规则稳定吗（还是每次危机临时加例外）？
- 规则有成本吗（还是只在主角需要时提供便利）？
- 规则会让不同阶层/职业/性格的人做不同选择吗？

### 1.3 世界观必须进入人物选择

礼法让人不能直说，于是借物传意；资源稀缺逼人二选一；地理季节改变行动时间与身体状态；
制度让善意必须经过手续、交换或风险；超自然规则让简单愿望产生长期代价。
**判断：删掉世界观专有名词后，人物仍能做同样的选择 → 设定还没成为叙事压力。**

### 1.4 文化材料

提供人物价值语言与身份记忆、场景秩序禁忌与感官质地、角色间共同理解或误解、
主题隐喻（隐喻必须在事件中承担后果）。使用前区分"资料正确"与"文学有效"，
资料必须经过角色、时代、阶层和叙事视角的过滤。

## 2. D2 故事性：从事件链到阅读动力

### 2.1 章节功能（不是固定配方）

章节可承担：建立新环境/规则；人物做改变后续的选择；升级冲突或压缩可选空间；
兑现局部承诺；推进关系或暴露裂缝；展示日常/恢复/价值观；重新理解已有事件；
高潮后的余波/哀悼/清算/重建；必要的等待/旅行/调查/准备（过程产生新信息、成本或关系变化）。

"安静"不等于"无事发生"：可能是一个人不再追问、一次没说出口的体谅、一件物品易主、
某个角色对风险的判断改变。

### 2.2 节奏四动力

| 动力 | 来源 | 过量 | 不足 |
| --- | --- | --- | --- |
| 紧张感 | 风险、时间压力、信息差、资源消耗 | 持续高压导致麻木 | 场景平铺无需继续读 |
| 期待感 | 问题、承诺、未完成行动 | 悬念堆积不兑现 | 下一步可预测 |
| 获得感 | 解决、成长、理解、关系确认 | 机械打脸、奖励通胀 | 长期只有受挫 |
| 余波感 | 代价、反思、关系重排 | 解释过度反复总结 | 高潮没有重量 |

### 2.3 反转与信息释放

反转 = 重新排列读者已有的证据，不是突然说出新事实。合格反转：事后可回溯证据/规则；
不破坏人物知识边界；让先前行为获得新解释；反转后局面更难；不一次性消费后续所有问题。

信息释放三种成本：理解成本（重组信息）、情绪成本（重新评价人/关系）、行动成本
（角色做更难的选择）。只给第一种成本是资料更新。

### 2.4 结构类型

| 结构 | 适合体验 | 主要风险 | 护栏 |
| --- | --- | --- | --- |
| 线性成长 | 跟随主角跨越障碍 | 升级循环重复、配角工具化 | 成长改变关系与价值选择 |
| 树状单元 | 每单元完整 + 汇入主线 | 单元无影响、主线稀释 | 每单元留下变化 |
| 网状群像 | 多人共同推动世界 | 视角混乱、中心承诺分散 | POV 责任、交汇点、信息差、主线锚点 |

## 3. D2/D3：从结构契约到现场过程

正文落地至少让读者经历"注意到什么 → 想做什么 → 受什么阻碍 → 如何判断 → 采取什么动作
→ 承担什么结果"的必要部分。安静/回忆/等待/余波可省略外部冲突，但不能把本应发生的
理解、关系或代价改写成作者结论。

## 4. D3 人物刻画：欲望、行动、声音与弧光

### 4.1 人物模型最小闭环

外在目标、内在需要、核心矛盾、恐惧/局限、资源/优势、关系压力、价值底线、错误策略、
代价承受、弧光。形容词（善良/冷静/聪明/腹黑）只有在具体场景表现为偏好、误判、动作、
语言和代价时才可写。

### 4.2 弧光四变化

认识变化、选择变化、关系变化、处境变化。最有力的弧光不是"知道正确答案"，而是
"知道代价仍选择承担"。审校找选择证据，不接受旁白宣布"他成长了"。

### 4.3 群像与主体性

重要配角至少要有：不依赖主角的欲望；自己的关系网络与责任对象；会伤害自己/他人的
错误策略；能拒绝/误解/利用主角的行动权；不同知识边界、语言习惯、价值排序；
独立日常质地（职业动作、生活习惯、私人承诺、独立矛盾）。且这些故事必须实际改变主角
的选择/资源/认知/关系，否则是旁支百科。

### 4.4 对话与声口

维度：词汇层级、句式节奏、信息策略（直说/试探/遮掩/反讽/误导）、关注对象、情绪防御、
权力位置（能否打断、是否用敬语）、变化边界。声口不是口头禅分配；**删掉角色名后，
读者仍能依据选择、句式和注意力判断说话者，才算差异。**

### 4.5 人物刻画场景证据

优先呈现：处理小麻烦的方式；无观众时做什么；对弱者/敌人/熟人是否不同标准；
如何使用/拒绝/隐藏/赠送物品；不能两全时选什么；如何说出不愿承认的情绪；
对环境的感受是否与他人不同。档案背景多但无行动/关系/感官证据，不算人物立体。

## 5. D4 感情线：从宣言到行动与不可逆变化

### 5.1 阶段抽象模型

注意 → 试探 → 识别 → 信赖 → 冲突 → 承担 → 重建。每阶段有主要问题和可观察证据，
不必机械按顺序。

### 5.2 承载物

对方记住并在关键时刻使用的小信息；无人要求时的照料/保护/等待/让步；共同承担的空间、
物件、任务和风险；同一动作在不同阶段的意义变化；拒绝或越界后的边界重商；
关系对主线选择的实际影响。同一意象重复时至少一项变化：拥有者、语境、人物理解、
关系阶段或代价。

### 5.3 审校信号（心理捷径）

刚认识就由旁白宣布深爱；一段心理总结替代多个可观察行动；误会无限拖延而无合理沟通
障碍；一方永远照顾等待牺牲而无主体欲望；感情线只在主线暂停时出现；冲突只靠"突然不
信任/吃醋"而无利益、认知、边界根因。修复 = 补人物行为、知识边界、关系阶段、后果，
不是写一句更强的情话。

### 5.4 非恋爱关系

亲情、师徒、朋友、同僚、敌手、群体归属遵循同一机制：
`关系期待 → 具体行动 → 对方解释 → 误差或确认 → 新边界 → 后续选择`

## 6. D1/D5 幽默、日常与烟火气

幽默来源：认知与现实错位；权力关系中的礼貌/推诿/装腔/反击；一贯偏执认真或不合时宜；
生活琐事与宏大目标并置；语言双关反讽误解（符合时代人物）；沉重事件后的不合时宜反应
（不取消事件后果）。审核：删除后人物是否失去可识别侧面；笑点来自当下处境而非插入段子；
是否破坏悲剧/严肃冲突/底线；不同关系前是否用不同幽默。

烟火气来自人物如何工作、等待、交易、照顾、争执、犯小错、处理物件；这些细节让世界
更具体并偶尔产生剧情或关系后果。不是堆食物和天气。

## 7. 文风与文笔：建立可变而稳定的声音

### 7.1 文风契约（可解释滑杆，不是作者名）

| 维度 | 可能的范围 | 审校问题 |
| --- | --- | --- |
| POV | 第一/限知第三/多 POV | 信息是否超出当前视角？ |
| 叙述距离 | 贴身体/意识 vs 远观察 | 内心/动作/旁白是否混淆？ |
| 时间方式 | 顺叙/回忆/预示/并置 | 跳转有清楚触发和代价？ |
| 句式节奏 | 短促/舒展/断裂/复沓 | 节奏随场景压力变化？ |
| 词汇层级 | 口语/书面/古典/专业/地方 | 用词属于人物和时代？ |
| 感官重心 | 视觉/听觉/触觉/嗅觉/身体 | 细节从 POV 注意力产生？ |
| 比喻密度 | 低/中/高 | 每个比喻增加理解或情绪？ |
| 对白比例 | 低/平衡/高 | 对白在做事而非传信息？ |
| 留白程度 | 直接说明→含蓄 | 省略处有证据可推断？ |
| 叙述态度 | 温柔/冷峻/讽刺/克制/热烈 | 稳定又能随人物变化？ |

### 7.2 中文语言的可读性与文学性

句子先保证主谓、指代、动作清楚，再谈诗意；长短句形成节奏但不每句切短制造金句感；
书面语/口语/古典语汇有角色与场景来源，不把典故当高级词库；比喻从人物此刻看见的世界
生成，同一核心意象重复必须发生意义变化；具体名词、动作、身体感受比抽象情绪词更能
进现场；情绪高潮可克制，但克制必须有动作/空间/声响承载，"不说"不等于没有文本证据；
文学性不等于降低可读性——读者能跟上因果、视角、说话者，才有余力感受语言。

### 7.3 段落微观结构

从「观察/感官 → 角色解释 → 身体或动作反应 → 关系反馈 → 选择/未选择」中选 2-4 项推进。
避免连续多段"抽象感受 → 哲理总结 → 解释意义"同一节奏；可改为物件、动作、对白停顿、
环境阻力、不完整的认知，让意义从读者拼接中产生。

### 7.4 旁白总结边界

**有用**：跨越时间、压缩重复过程、建立历史视野、处理不适合逐场呈现的事实、形成叙述者
特殊声音。**危险**：代替关键选择、代替感情发生、代替误解/理解过程、在无证据时替人物下
结论、连续复述刚发生的蓝图/审核意见/章节目标。判断方法：删掉总结后读者是否仍能从行动
和细节理解变化；不能则补正文证据，而不是只删词。

### 7.5 AI 味专项（机制层，不是禁词表）

"AI 味"不是可靠单项分数，也不是某个词出现一次能证明的属性。真正要修的是可由读者指出
的预测性、空泛、同构、越界或声部失真。通用修复顺序：事实/因果 → 场景承载 → POV/声部
→ 段落节奏 → 句法/词语。不承诺绕过检测器，不把任何作者的具体句式变成生成模板。

| 可观察症状 | 共享根因 | 优先修复动作 |
| --- | --- | --- |
| 正文像蓝图/审核报告 | 规划与正文输出边界未分，场景承载不足 | 先移元信息，再补 POV 可经历的动作/观察/对白/后果 |
| 事件快但没重量 | 事件数量当推进，心理标签当心理过程 | 回场景目标/阻力/选择/退出，补最小必要过程 |
| 段落同一模板 | 写作任务过度公式化 | 保留因果责任，改变信息抵达/观察顺序/动作比例/停顿 |
| 人物统一腔调 | 声部没进入行动，叙述底色吞没差异 | 从知识边界/利益/关系/压力重写对白与观察 |
| 语言精致但现场空 | 先追文学感再补经验 | 先补具体证据，再删无新增意义的修辞 |
| 修订更顺但更像机器 | 修订层级过低，只换词 | 按根因顺序修订，保护未受影响的段落 |

## 8. 开篇与结尾

开篇尽快建立：具体可感的现场；正在发生/即将发生的异常或压力；值得跟随的 POV
（欲望和处境可理解）；一条读者问题或承诺；与作品相称的语言声音。失败不是"慢"，
而是没有方向：背景名词与百科在人物做出选择前堆积。

结尾处理：核心主题问题在人物行动层面得到回答；主线承诺兑现或有意反转并说明代价；
主角与重要配角的状态和关系有落点；世界是否改变、谁承担后果、哪些可开放；最后一幕
情绪与全书承诺相称。常见问题：前面不断扩张规模，结尾只能旁白快速概括。
应在中后期逐步关闭支线、回收核心意象、收敛到人物最难的选择上。

## 9. 类型适配

| 类型 | 核心承诺 | 重点设计 | 典型退化 |
| --- | --- | --- | --- |
| 仙侠/玄幻 | 探索、成长、秩序与自我超越 | 规则成本、境界意义、势力制度 | 战力通胀、境界报表 |
| 武侠/历史架空 | 江湖/政治/伦理选择与风骨 | 身份秩序、资源名分、行动后果 | 只写名场面和金句 |
| 都市/现实 | 熟悉生活中的欲望与困境 | 职业流程、经济压力、社会网络 | 标签化人物、方便巧合 |
| 言情/情感 | 关系变化与情绪回报 | 双方主体性、边界、行动证据 | 一方工具化、误会拖延 |
| 悬疑/推理 | 追踪问题并重新理解证据 | 信息差、公平线索、行动后果 | 隐藏信息、反派降智 |
| 科幻 | 新技术/制度下的人类处境 | 技术约束、伦理代价、陌生化细节 | 术语展览、科技万能 |
| 群像/多 POV | 多人的选择共同改变局面 | POV 责任、信息地图、交汇点 | 视角漂移、主线失焦 |

类型规则是读者合同，不是免除人物、语言和主题责任的借口。

## 10. 精品网文与文学性的平衡

- **类型回报与人物处境可以并存**：读者既想要类型承诺的爽点/悬念/关系回报，也想要人物
  像人、世界有质地。精品化 = 在兑现类型承诺的同时不牺牲人物主体性和叙事诚实。
- **把宏观设定压回具体生活**：读者相信世界，不是读到更多名词，而是规则改变了人的工作、
  等待、交易、身体和关系。
- **人物声音和 POV 是信息控制器**：叙述方式由人物的知识、身份、经验和注意力决定，
  不由默认文风决定。
- **长篇推进单位是状态与意义的变化**：新事件只有改变资源/关系/认知/承诺/风险/后续选择
  才形成可追踪的推进。
- **质量改进必须看证据**：评分、榜单、评论、模型自评只能触发调查；最终回到正文片段、
  事实/状态、跨章回归和修订后的局部副作用。

## 11. 从优秀作品提炼可迁移经验

对任何作品案例，回答：
- 作品效果由什么具体机制产生，不是由作者名字保证？
- 该机制影响 D1-D5 哪些维度？
- 适合哪些类型、POV、章节功能？在哪些情况下变成拖沓/说教/模仿？
- 能否说明涉及的正文现象或结构化状态，而不是逐字匹配？
- 如何验证原失败场景和一个题材/关系/功能明显不同的反例都没被误伤？

## 12. 可执行审校矩阵

### D1 世界观
W1 规则可内化（随机抽规则能否推导后果）；W2 设定承载主题；W3 跨章一致；W4 世界独立质地；
W5 文化材料有来源。

### D2 故事性
S1 章节功能成立（实际完成什么变化）；S2 因果由人物驱动；S3 伏笔可回溯（有来源证据且增加
新意义）；S4 节奏匹配功能；S5 线路可管理；S6 回报不是机械。

### D3 群像
E1 配角有独立欲望；E2 声部可区分（遮名后可识别）；E3 弧光可观察；E4 关系网络动态；
E5 主体性不被主角吞没。

### D4 感情线
R1 行动承载；R2 阶段转变有证据；R3 与主线交织；R4 双方主体性；R5 有责任/自由/信任/伤害/
修复张力。

### D5 幽默
H1 来自人物与处境（删除后失去信息）；H2 时代/类型契合；H3 调节而非打断（保留严肃后果）；
H4 角色一致。

### 跨维度
- **视角**：谁看到/知道/误解，叙述是否泄漏不该出现的信息。
- **连续性**：人物状态、伤势、资源、地理、时间、关系、知识是否一致。
- **具体性**：情绪和主题是否有行动、环境、物件、身体反应承载。
- **声音**：叙述者、POV 人物、对白各自成立。
- **AI 退化信号**：规划泄漏、摘要替代过程、段落同构、抽象过密、声部趋同且已造成损害。
- **原创性**：直译、套句、过度可识别模仿、泛化套话。
- **后果**：本章结束后什么无法无痕恢复？无不可逆变化时是否有明确的静态章节功能。
- **回收**：是否引入无法管理的承诺、人物或剧情线。
