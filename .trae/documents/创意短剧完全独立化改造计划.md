# 创意短剧完全独立化改造计划

## Summary

剧本创作板块当前「入口独立、存储依附」：创意短剧必须挂在某个小说项目下（`artifacts.project_id` NOT NULL 外键 + `loadProjectTitle` 404 校验 + 前端强制选择作品）。本计划把创意短剧改为**完全独立于小说项目**：新建 `short_scripts` 独立表（项目关联字段可空）、新增项目无关 REST 端点、MCP `projectId` 变可选、前端作品选择器降级为可选「关联作品」。保留「关联作品」作为可选能力（为小说世界观拍衍生短剧时选用）。小说章节转剧本（chapter-script）路径不动。

## Proposed Changes

### 1. 数据库迁移 `deploy/postgres/050_short_scripts.sql`（新建）

```sql
CREATE TABLE IF NOT EXISTS short_scripts (
  id TEXT PRIMARY KEY,
  project_id TEXT REFERENCES novel_projects(id) ON DELETE SET NULL,
  idea TEXT NOT NULL,
  instruction TEXT,
  target_duration_seconds INTEGER NOT NULL,
  source_fingerprint TEXT NOT NULL,
  contract_version TEXT NOT NULL,
  object_key TEXT,
  content_hash TEXT NOT NULL,
  workflow_id TEXT NOT NULL,
  payload JSONB NOT NULL DEFAULT '{}'::jsonb,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE UNIQUE INDEX IF NOT EXISTS ux_short_scripts_fingerprint ON short_scripts(source_fingerprint);
CREATE INDEX IF NOT EXISTS idx_short_scripts_project ON short_scripts(project_id) WHERE project_id IS NOT NULL;
```

数据迁移（幂等，可重放）：把既有 `artifacts WHERE kind='short-script'` 复制进新表（id 沿用原 artifact id，`project_id` 保留为关联作品，payload 从 `artifacts.payload` 提取，`object_key` 沿用）；`artifacts` 原行保留作审计历史（符合 AGENTS.md「数据迁移不重写历史」）。迁移后运行 `pnpm novel:v2:migrations audit` 验证。

### 2. Repository 方法（`src/novel-v2/postgres-repository.ts`）

新增四个方法（INSERT/SELECT 直写 `short_scripts`，不经过 artifacts）：
- `recordShortScript(row)` — INSERT（fingerprint 冲突时 ON CONFLICT DO NOTHING）
- `getShortScript(id)` — by id
- `findShortScriptByFingerprint(fingerprint)` — 幂等查询
- `listShortScripts(options: { projectId?: string; limit: number })` — projectId 存在时过滤关联作品，否则返回全部（独立的 + 关联的）按 created_at 倒序

### 3. 应用层 `src/novel-v2/application/short-script-h3.ts`

- `generateShortScriptH3` input：`projectId` → `projectId?: string`

- 幂等指纹：`${input.projectId ?? "independent"}:${idea}:...`（作用域隔离：同一创意独立模式与关联模式是两个产物）

## Assumptions & Decisions

1. **旧数据不删除**：artifacts 中 kind=short-script 的行保留作审计；新表为唯一读写目标（迁移 SQL 一次性带入）。
2. **幂等作用域隔离**：独立与关联两种模式同一创意视为不同产物（指纹含作用域前缀），避免跨作用域误复用。
3. **列表语义**：无过滤=全部短剧（独立+关联）按时间倒序；前端选择器只做过滤与创作时关联。
4. **章节剧本路径零改动**：chapter-script-h3 仍走 artifacts（它本来就依赖定稿章节，天然项目内）。
5. **契约版本升级**：存储结构变更（表+字段）升 SHORT_SCRIPT_CONTRACT_VERSION 至 "2"；旧产物读取兼容（迁移后 payload 结构一致）。
6. **model_invocations 审计**：workflowRunId 前缀 `short-script:` 不含项目，归因逻辑（验证脚本按时间窗+前缀过滤）不受影响。
