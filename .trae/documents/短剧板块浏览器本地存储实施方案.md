# 独立短剧板块浏览器化（IndexedDB 本地存储）实施方案

**状态（2026-09-19 核对）**：本方案已按文实现，是**当前架构的说明**而非计划——`src/lib/shortDramaStore.ts` 在场，短剧生成为无状态 `POST /v2/short-script-h3`（`scripts/novel-v2-api.ts`），依赖 `idb-keyval`。它取代了同目录「短剧创作台公用素材与多剧情计划」的服务端方案；后者留下的两张表已是死表（见那篇的状态注）。

## Context（为什么做）

用户希望「短剧板块（小说的短剧除外）」不再存数据库，直接存浏览器。已确认决策：
1. **生成走后端、存储走浏览器**：独立短剧的分镜生成仍用后端模型管线（提示词装配/LLM 网关，质量不降），但产物与创作台/素材**不落 Postgres**；前端把生成结果存入浏览器 **IndexedDB**。
2. **移除独立短剧的 DB 持久化 + MCP 工具 + per-resource REST 端点**；仅保留**单个 stateless 生成端点**（调和「后端生成」与「移除 DB/端点」）。小说派生章节短剧（chapter-script，DB artifacts）**完全不动**。
3. **放弃存量**：数据库里既有独立短剧/创作台/素材不迁移，浏览器端从头开始；已应用的迁移文件保留（数据放弃不作 schema 回退，避免迁移审计抖动）。

落点回顾：独立 `short_scripts` 表 + `short_drama_workspaces/materials`（迁移 050/090）当前由 REST（`scripts/novel-v2-api.ts`）、MCP（tool-definitions/handlers）、应用层（`short-script-h3.ts`/`short-drama-workspace.ts`）、repo 读写；前端 `ScriptStudioPanel.tsx` + `novelApi.ts` 走这些 DB 端点。

## 目标架构

- 前端新增 `src/lib/shortDramaStore.ts`：基于现成 `createRepairingStore`（`src/lib/indexedDbStore.ts`，依赖 `idb-keyval@^6.2.6` 已在 package.json），DB `ymcp-short-drama-db` 下三个 store（workspaces / materials / scripts）。图片以 **Blob** 存 IDB，渲染用 `URL.createObjectURL`（卸载 revoke）——参考 `src/lib/imageStore.ts` 的现成模式。索引在 DAO 层用 JS 过滤（量级小；真实 IDB index 标 TODO P2）。
- 生成：前端点「生成」→ `POST /v2/short-script-h3`（**stateless**：去掉落库与 DB 幂等复读，直接返回新 record）→ `saveScript` 落 IDB → 前端用本地幂等键去重。素材解析改在前端（从 IDB 读选中素材组 `referenceMaterials`/`materialRefs`）。
- 移除：独立短剧的 GET/list/DELETE 端点、项目级 short-script 端点、`/v2/short-drama-workspaces/**`、全部独立短剧 MCP 工具（`novel_short_script_h3`/`_brainstorm`/`_submit` + 7 个 workspace/material）。保留 `novel_chapter_script_h3`/`_submit`/`novel_skill_get` 与 chapter-script REST。

### B. 前端 IndexedDB 存储层（新增）

**`src/lib/shortDramaStore.ts`**（复用 `createRepairingStore` + `idb-keyval`）
- 记录形状：
  - `WorkspaceRecord { workspaceId; title; description?; createdAt; updatedAt }`
  - `MaterialRecord { materialId; workspaceId; description; fileName?; mimeType?; contentHash; blob: Blob; createdAt }`
  - `ScriptRecord { scriptId; workspaceId?; materialRefs?; idea; instruction?; durationMode; targetDurationSeconds; sourceFingerprint; localKey; plotBeats; creativeStrategy?; cinematicHints; characters; segments; createdAt }`
- DAO（token 中文注释、真实 IDB index 标 TODO P2）：
  - workspaces：createWorkspace / listWorkspaces / deleteWorkspace（级联删 materials + 解除 scripts.workspaceId）
  - materials：addMaterial({workspaceId,description,file:File})（`crypto.subtle` 算 contentHash，同 ws 去重，blob 入 IDB）/ listMaterials(ws) / getMaterial / updateMaterialDescription / deleteMaterial
  - scripts：saveScript / listScripts(workspaceId?)（JS 过滤；undefined=无创作台）/ getScript / deleteScript / findByLocalKey(scope,localKey)（前端幂等）/ findByFingerprint / listRecentIdeas(limit)（供 avoidMotifs）
  - 工具：clearAll()

**`src/hooks/useShortDramaMaterialUrl.ts`**：`useMaterialObjectUrl(workspaceId, materialId)`，维护 `Map<materialId,{url,blob}>`，卸载/替换时 `revokeObjectURL`。

**`src/lib/__tests__/short-drama-store.test.ts`**：用 `fake-indexeddb`（已 devDep）测 DAO（CRUD、contentHash 去重、workspaceId 过滤、本地幂等 findByLocalKey）。
