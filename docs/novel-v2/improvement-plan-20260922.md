## 迭代 1：生成侧增量防御（下一本书/下一卷生效）

### 1A. 兑付分布信号：连续零结清游程检查（P1，最高优先）

- **根因**：dueLedger 只看"单条账是否到期"，不结清分布是**一组章的属性**——组级病灶用不了行级判据（skill 实证）。049-060 十二章净收益为负、061-091 结清 0 笔，没有任何门看见，因为没有任何判据的输入是"结清事件的序列"。
- **改动**：在 `application/story-arc.ts` 仿照 `inspectStoryArcEnsemble` 新增纯函数 `inspectPayoffRhythm`（名暂定）：
  - 输入：本批章节的台账结清事件序列（promises/foreshadowing fulfilled 时间戳 → 章号）。
  - 判据（三个候选先跑真实语料回放择优，**禁止直接定阈值**）：①最长连续零结清章游程；②近 N 章结清/净增悬念比；③每弧结清率下限。
  - 产出：并入 `serial-signals` 上下文段（描述性统计），弧审核 prompt 注入判定契约（游程 ≥8 章且读者净收益受损才报，过渡弧豁免须 planningRationale 声明）。
- **边界**：warning/审核意见级，不做硬门；"过渡弧"合法存在，判据只要求声明。
- **验证三件套**：168 章真实回放（预期命中 049-060 / 061-091 两个历史游程）；与人工审核结论对齐；分母诚实（报游程数时注明多少属正常蓄势）。

### 1B. 收尾形态轮换：closureRhythm 从"基线"升为"带配额的指引"（P1）

- **根因**：style-contract 的 `closureRhythm` 维度只能描述"惯用收束式"，无法表达"≥1/3 章换形态"的配额；ending-ritual 门按滑窗触发，天然漏掉区段首章（窗口判据固有边界）——生成侧没有轮换压力，门只会事后报警。
- **改动**：
  1. `prompts/` 章节正文生成契约段注入：**每批 ≥1/3 章改用非仪式收尾**（旁人闲话 / 外部小事件 / 硬冲突切章），并轮换仪式的表层实现（共享动作帧可以保留，表层句式必须变体——"仪式是动作帧不是句子"）。
  2. 弧审核注入收尾分布统计（近批末句长度/形态直方图），配额未满足才报。
  3. `ending-ritual` 判据演进（可选，回放验证后再决定）：补"段落级回溯判定"覆盖区段首章。
- **边界**：不改 style-contract 维度结构，只在 payload 语义与 prompt 注入层扩；**不做末段长度类总量判据**（已被数据证伪：精确率 0.24，误报 18 章）。
- **验证**：生成 3-5 章试点 → ending-ritual 窗口读数应从"连续命中"降为"离散命中"；人工复核收尾形态分布。

### 1C. 半X 减频：指引配额，不升硬门（P2）

- **理由**：精修实证"门读数 ≠ 文本有病"——25 个命中章改 9 判 D 16；同动作复写 ≥3 次且无语义增量才是病，**硬门会逼模型为过门而删掉认知语汇与戏剧装置**（skill 铁律）。
- **改动**：
  1. 章节正文生成契约注入软配额：计量刻度词每章 ≤4 处（对齐门阈值），超配额时"留最有力一处，其余换直陈或换感官"。
  2. **口径统一**：门内 `MEASURE_UNITS`（拍寸分步刻晌指口，7 单位）与扫描口径（11 单位）不一致——先跑两套口径对 168 章的差集，若宽集多出的命中集中在少数词（如"半口气/半声"），在门注释里写明收窄理由（防"三步/一分"误伤的原始校准），TODO 标配置化。**禁止为了数字好看直接扩集**。
- **验证**：差集逐词人工归类（病/手段/正常中文），只把"病形态"的新单位入集，双向测试（新增单位命中 + 反例不误伤）。

## 迭代 2：低风险存量修补（本轮书可直接做）

### 2D. 开篇 1-3 章钩子加固（P2，改动最小、商业收益最直接）

- **范围**：001 章末段。现收尾"但那件事，得等他能站稳脚跟之后再想"是延宕，不是卡点。
- **动作**：章末落到硬冲突切章（例供催缴上门 / 验灵根异动，取材自已有事实，不新增设定）；002/003 复核卡点后同法。改后重跑门（tic 三通道 + ending-ritual + paragraph-rhythm 零新增告警），落库走可逆三步（单章 revision+1，hash 校验）。
- **边界**：只动章末 1-2 段，不动开篇已成立的声口与信息布局（黄金三章基本盘是达标的）。

### 2E. 章长下限信号（P2，先考古再动手）

- **前置**：`manuscript.length` 在 `RETIRED_STRUCTURAL_RULES` 中被退役——先查退役记录/原因，避免复辟已被否决的规则。若当年因"长度本身不是病"退役，则新判据必须**只盯分布异常**：单章 <1800 字（warning）且同书近 6 章均长下滑超 15% 才报，终章/过场章豁免声明。
- **改动**：`manuscript-structure.ts` 新 warning 通道 `manuscript.length-drift`，阈值常量放叶子模块 + TODO 配置化 + 双向测试。
- **验证**：168 章回放——预期命中末段风险带（141-168 均章 2054、53 个 <2000 字章），1-20 章（均 2814）零命中。

## 迭代 3：存量重改写（试点制，先小后大）

### 3F. 章末仪式重灾区批次改写（P1 存量侧）

- **范围**：窗口命中的 38 章中先取重灾连续段 **70-92**（23 章）试点，验证后再决定 53-55 / 113-136 / 166-168 是否跟进。**不全本回炉**：仪式是风格惯性与剧情功能（清点=心灵史）的混合体，先归类（四形态：仪式动作帧 / 认知语汇 / 配对构造 / 戏剧装置），只改第一类。
- **流程**（复用 skill 批次纪律）：全量备份 → 逐章全文读 → 末段/末句改写（**共享动作帧保留、表层句式换体**；不删字）→ 重跑门（tic 三通道读数不得变坏、ending-ritual 窗口读数下降）→ hash 比对生成改动清单 → 可逆落库 → 复验。
- **验收**：试点段 ending-ritual 命中章数下降 ≥60%；人工抽读确认"章末仍可安心睡觉但不全是同一落点"；门零新增告警。

### 3G. 51-80 死亡象限对白试点（P1 存量侧，最高风险，最后做）

- **范围**：先取 2-3 章试点（候选：055 / 062 / 077——半X 高发且零对白叠加章）。动作：把独角戏中的**关键信息揭示**改为与在场第二人的交锋（学字人/繁主事本就在场不试探，F4 诊断已指出这是"自觉极简"的临界），不改事件因果、不新增人物。
- **风险与边界**：这是全书最深的结构债，**强改会毁声口**。试点两章独立评审（两轮子代理 + 取证纪律 + 交叉验证），若评审判"改后声口失真"，则**接受该区间为本书的既定形态**，只把教训写进 style-contract 的 dialogueRatio 配额（下一本书生效），并停止扩面——判据测不到的语义层（段落在不在语义节拍上、独处是不是有意）不强行自动化。
- **验收**：试点章对白段/千字 ≥1.5；蓝图 participants ≥2 且互施代价；门零新增告警；独立评审"可定稿"。

## 迭代间共享的验收纪律

1. **任何新判据交付前出三件套**：真实通道回放命中数（`import` 真实函数，只换数据源）、与人工判读吻合度、分母诚实（正常运行的占比）。
2. **双向测试 + 反例**：命中面取自真实语料病章，反例至少两个形态各异（含用户认可章零命中）。
3. **spec 同步**：每个新门/新契约在 `docs/novel-v2/workflow-map.md` 记设计意图、输入输出、被证伪的旧方案（防重提）。
4. **门读数 ≠ 文本有病**：存量处理一律先逐章归类再动手，判 D 也是交付物。
5. **落库三安全网**：全量备份、回滚锚点 SQL、幂等护栏；改动清单以 hash 比对为唯一权威，账本不算数。
