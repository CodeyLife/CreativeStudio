# 高质量中文长篇小说创作参考手册

> 版本：v1.1
> 更新时间：2026-08-03
> 适用范围：novel-v2 的创作规划、章节生成、审校、修订、事实提取与 learning 迭代
>
> 本文是可迁移的创作经验与工程化参考，不是某一位作者的仿写指南，也不是要求每一章机械完成全部技巧的检查表。所有原则都必须服从当前作品的题材、叙事视角、章节功能、人物知识边界和作者已经批准的创作契约。

## 0. 使用边界与证据分级

### 0.1 这份文档解决什么问题

高质量长篇不是“把更多设定、金句、反转和情绪塞进正文”，而是在长期写作中同时维持以下几件事：

1. 读者知道自己为什么要继续读，并且每一阶段都获得了新的问题、情感或认知回报。
2. 人物的欲望、局限和关系推动事件，事件又反过来改变人物，而不是人物被大纲拖着走。
3. 世界有规则、历史、利益和日常质地；设定会限制选择，也会制造代价和主题，而不只是提供升级资源。
4. 语言有稳定的叙事声音，但能随 POV、人物、场景压力和情绪温度变化。
5. 长线伏笔、事实、承诺、关系和状态可以追踪、兑现、修订和回滚。
6. 每次修订都改善明确问题，同时保护已成立的事实、人物主体性、声音差异和后续可写空间。

### 0.2 证据分级

本文将资料分为四级，使用时不能混淆：

| 级别 | 证据 | 用法 | 局限 |
| --- | --- | --- | --- |
| A | 作家、编辑、作协媒体的公开创作谈 | 支撑创作者自述的方法与价值取向 | 自述不等于作品全部机制，也不等于普适公式 |
| B | 高等院校课程、叙事学与故事生成研究 | 支撑概念、结构、视角、人物网络、情绪线等抽象模型 | 研究结论需要转化为具体文本证据，不能直接替代审美判断 |
| C | 指定作品的文本细读与跨作品对照 | 提炼“如何实现效果”的机制假设 | 不复制原文，不把单一作品偏好升级为全局规则 |
| D | GitHub 开源工具、工作流和 README | 参考数据结构、阶段划分、回归与人机协作方式 | README 是项目自述；必须审查许可证、活跃度、测试、数据边界和实际代码 |

### 0.3 版权与风格使用原则

- 研究作品只提炼结构机制、叙事决策和可观察效果，不搬运原句、段落、独特比喻或人物台词。
- “文风参考”应记录为抽象特征组合，例如叙述距离、句式密度、对白比例、意象使用方式、幽默来源和情绪留白；禁止把“写成某作者”作为生产契约。
- 对在世作者的作品，优先学习可解释的技法，不生成高度可识别的个人风格复制品。
- 任何来自外部项目的提示词、范文、训练数据或源码，在进入项目之前都要做许可证与来源审核。
- 本文中的“正例”是机制示意，不是需要逐句仿造的模板；“反例”是失败类别，不是精确短语黑名单。

### 0.4 如何从优秀作品提炼经验

本文不声称存在一份客观、永久不变的“最高评分小说”名单。作品案例采用多种评价信号交叉选择：重要奖项或权威榜单、长期传播、专业评论、作者公开创作谈，以及网文特有的连载反馈。它们只能说明作品值得研究，不能把读者热度直接等同于文学质量。

每个案例都按以下链路处理：

```text
外部证据 → 正文中可观察的叙事决策 → 可迁移的机制假设
→ novel-v2 的结构/提示词/审校投影 → 适用边界与反例回归
```

“作者这样说”只证明作者的创作意图或工作方法；“作品里反复出现”才支持文本机制假设；“对不同题材和章节功能都有效”才值得进入共享契约。研究结果不复制原句、人物、情节或个人文风，也不因为某部作品的成功就把其篇幅、节奏、悲剧程度、爽点密度或叙事视角升级为硬规则。

## 1. 总结：高质量长篇的十四条稳定原则

1. **先定读者承诺，再定事件规模。** 读者期待的是一组可持续兑现的体验，不只是世界观名词。
2. **主题不是口号，而是选择压力。** 主题要进入人物在利益、关系、责任和代价之间的具体选择。
3. **故事的最小动力是“欲望遇到阻力后产生选择”。** 没有选择，事件只是搬运；没有代价，转折就没有重量。
4. **每一层大纲都必须能回答“谁想要什么、什么阻止他、他怎么选、选后改变了什么”。**
5. **大纲要给方向和边界，不要把正文锁成待办清单。** 蓝图应规定不可破坏的因果、状态和功能，同时留下现场发现的空间。
6. **人物不是设定卡片，是持续做决定的人。** 背景只有在现在的行动、关系、语言和偏见中产生可观察后果时才有价值。
7. **配角必须拥有离开主角也成立的欲望、关系、秘密、工作和代价。** 群像不是角色数量，而是彼此选择会改变彼此的网络。
8. **感情线要由行动、物件、习惯、误解、牺牲与共同承担累积。** 心理总结可以解释，不能代替发生。
9. **世界观要成为压力系统。** 规则、制度、资源、阶层、地理和文化应真实地改变人物可用的选择集合。
10. **文笔服务于视角和情绪。** 华丽不等于高级；最合适的语言是能让读者感到“此刻只能这样说”的语言。
11. **节奏是张弛与回报的分布，不是每章都加速。** 行动、转折、高潮、余波、相处、恢复和内省都有成立条件。
12. **留白必须让读者有证据可推断。** 留白不是省略因果，也不是用模糊代替具体。
13. **长篇要管理疲劳。** 反复出现的冲突、升级、误会、反转和意象必须改变层级、意义或代价。
14. **质量判断必须回到证据和回归。** 分数只能指示问题，不能证明修订有效；必须看正文、状态变化、事实和跨场景结果。

## 2. 全局规划：从创意到可持续长篇

### 2.1 先写创作契约，不要先堆百科设定

项目初始化至少需要形成以下字段。它们不是最终正文，而是后续所有规划和审校共享的约束源：

| 字段 | 要回答的问题 | 合格信号 | 常见误区 |
| --- | --- | --- | --- |
| 读者承诺 | 读者持续阅读会获得什么独特体验？ | 可描述为体验与冲突组合 | 只写题材标签或“爽、甜、虐” |
| 核心前提 | 这部作品最不可替代的假设是什么？ | 一句话能看出人物、压力和反常点 | 只是世界观介绍 |
| 主题问题 | 作品持续追问什么？ | 能转化为人物选择，例如自由与责任如何冲突 | 写成作者结论或宣传语 |
| 主角需要 | 主角真正缺少的内在能力或认识是什么？ | 与外在目标不同，能随事件改变 | 把“变强”当成全部需要 |
| 主角矛盾 | 主角同时想要哪两件互相牵制的东西？ | 每次重大选择都可触发矛盾 | 只写性格形容词 |
| 核心对抗 | 什么人、制度、环境或价值会持续阻止主角？ | 对抗者有自己的合理目标与资源 | 反派只负责作恶和送经验 |
| 情感契约 | 读者希望见证哪种关系变化？ | 能写出阶段、行动证据和不可逆节点 | 只写“男女主感情线丰富” |
| 世界锚点 | 哪些地方、制度、物件或习俗让世界有独特质地？ | 至少能进入场景和人物选择 | 设定只存在于说明书 |
| 研究需求 | 哪些事实需要外部资料、专家或实地观察？ | 有来源、可信度和使用范围 | 把查到的资料原封不动塞进正文 |
| 不可妥协项 | 哪些主题、人物边界、结局边界不能被生成过程覆盖？ | 可审计、可解释、可版本化 | 把所有偏好都写成硬门禁 |
| 结局包络 | 结局必须回答什么，哪些内容可以开放？ | 有兑现责任和允许留白的范围 | 只预写最后一幕 |

本项目的 `creativeBrief` 已有类似字段；新增经验应优先落入这些正式输入，不要在多个 stage prompt 中各自重复定义一套互相矛盾的目标。

### 2.2 五层规划法

规划要从粗到细，每一层只承担自己最擅长的决策：

| 层级 | 产物 | 核心问题 | 不应承担的工作 |
| --- | --- | --- | --- |
| L0 作品承诺 | 一句话前提、读者承诺、主题问题 | 为什么是这部作品？ | 详细事件流水 |
| L1 全局骨架 | 起点、不可逆转折、终局方向、主线与主要支线 | 整体朝哪里变化？ | 每章对白和景物 |
| L2 分卷/故事弧 | 弧目标、局部对抗、人物阶段、伏笔窗口、出口状态 | 这一段解决什么并留下什么？ | 把每章写成摘要堆 |
| L3 章节蓝图 | 本章功能、POV、起始状态、发展轴、转折、余波、承接压力 | 本章完成什么变化？ | 逐句规定正文 |
| L4 场景计划 | 场景目标、参与者、阻力、动作、信息差、感官锚点、退出状态 | 这一场如何让状态改变？ | 把场景变成信息讲义 |
| L5 正文 | 具体动作、对白、叙述、细节与节奏 | 读者如何经历这一变化？ | 回显蓝图和审核说明 |

规划从 L0 逐层展开，但也要允许“向上回写”：正文或审校发现了真实的缺口，先记录证据，再更新相应的世界、角色、弧或事实契约，并检查下游影响。不能只改当前章节来掩盖上游设计问题。

### 2.3 事件因果模板

每个重要事件至少用以下结构描述：

```text
触发条件 → 人物欲望 → 阻力/代价 → 可选方案 → 人物选择 → 即时结果
→ 状态变化 → 新问题/新承诺 → 后续影响
```

一个转折是否有力，重点不在“事件够不够大”，而在于：

- 选择是否由人物已经建立的欲望、认知、关系和局限共同产生。
- 人物是否知道自己在失去什么，或者至少让读者能从信息差中理解代价。
- 结果是否改变资源、关系、知识、立场、身份、承诺或行动空间。
- 新问题是否由前一个选择产生，而不是随机掉落的新线索。
- 转折是否会让后续人物无法无痕回到原来的状态。

### 2.4 规划的三种不确定性

长篇不能把所有未知提前填死。应把不确定性分成三类：

1. **设计不确定性**：作者尚未决定的内容。可以保留为候选方案，但不能偷偷当成事实注入正文。
2. **人物不确定性**：人物不知道的真相。可以作为戏剧性信息差，但作者视角、角色视角和正文事实必须分层。
3. **读者不确定性**：正文有意暂不说明的内容。必须能从已经出现的行动、物件、语言或规则中推断，否则只是悬空。

审核时要检查：哪些信息是隐藏，哪些信息是缺失；哪些伏笔是延迟兑现，哪些只是忘记回收。

### 2.5 伏笔与承诺账本

伏笔不是“出现一个神秘名词”，而是一个未来可被重新解释的叙事承诺。建议每条记录包含：

| 字段 | 说明 |
| --- | --- |
| `promiseId` | 稳定标识，不用标题或章节号作为唯一身份 |
| `setupEvidence` | 埋设正文证据，包含来源版本和叙事时点 |
| `readerQuestion` | 读者会自然产生的具体问题 |
| `possiblePayoffs` | 一个或多个可行兑现方向，标记设计态而非事实 |
| `payoffWindow` | 预计在哪个故事弧或阶段处理 |
| `status` | seeded / active / paid-off / reinterpreted / abandoned-with-reason |
| `payoffEvidence` | 兑现时引用正文中的实际行动或信息 |
| `meaningDelta` | 兑现后相较埋设时增加了什么新意义 |
| `cost` | 兑现是否改变关系、资源、真相或人物选择 |

好的兑现通常满足“回看能认出，第一次看不必懂；兑现后意义升级，而不是只揭晓答案”。

### 2.6 多线规划

多线不是同时开很多名字，而是多个目标和因果网络在有限篇幅内相互影响。每条剧情线应明确：

- 线的核心问题与推动者。
- 当前状态、主要阻力、下一次可见变化。
- 与主线的耦合方式：改变人物选择、资源、认知、关系或世界规则中的至少一项。
- 何时交汇、何时退出、何时转化为另一条线。
- 若暂时不推进，读者仍能感到它处于什么状态。

如果一条支线既不改变主线，也不提供独立的情感、认知或世界经验，就应该合并、缩短或删除，而不是靠增加角色和地点维持存在感。

## 3. 故事剧情：从事件链到阅读动力

### 3.1 故事不是大纲复述

正文的叙事动力来自“人物正在试图做什么”，而不是“作者接下来要介绍什么”。场景可以用五问判断：

1. 谁在主动争取什么？
2. 谁或什么在阻止他？
3. 参与者掌握的信息是否不同？
4. 他们有什么选择，哪个选择会带来真实代价？
5. 场景结束时，至少哪一个状态发生了变化？

如果五问都只能回答“他们讨论了设定、回忆了过去、等待下一件事”，这通常是信息展示或过渡材料，还没有形成可读的戏剧场景。它仍可能作为安静章节的一部分存在，但必须有情绪、关系、认识或承诺上的变化。

### 3.2 章节功能不是固定配方

章节可以承担以下一种主导功能或几种相互支持的功能：

- 建立新环境或新规则。
- 让人物做出会改变后续的选择。
- 升级冲突或压缩可选空间。
- 兑现局部承诺。
- 推进关系阶段或暴露关系裂缝。
- 展示人物日常、恢复、相处和价值观。
- 让读者重新理解已有事件。
- 承担高潮后的余波、哀悼、清算和重建。
- 提供必要的等待、旅行、调查或准备，但让过程本身产生新信息、成本或关系变化。

“安静”不等于“无事发生”。安静章的变化可能是一个人不再追问、一次没有说出口的体谅、一件物品从谁手里转到谁手里，或者某个角色对风险的判断发生改变。

### 3.3 节奏：紧张感、期待感、获得感与余波

节奏不是“越快越好”。可以把读者体验拆为四种相互作用的动力：

| 动力 | 来源 | 过量症状 | 不足症状 |
| --- | --- | --- | --- |
| 紧张感 | 风险、时间压力、信息差、资源消耗 | 持续高压导致麻木 | 场景平铺，无需继续读 |
| 期待感 | 问题、承诺、未完成行动、关系悬念 | 悬念堆积不兑现 | 下一步可预测且无新问题 |
| 获得感 | 解决、成长、理解、关系确认、价值选择 | 机械打脸、奖励通胀 | 长期只有受挫和拖延 |
| 余波感 | 代价、反思、关系重排、现实后果 | 解释过度、反复总结 | 高潮像没有发生，重量消失 |

建议以“波浪状上升”组织故事：一个局部单元解决问题或化解危机后，下一单元引入更高层级的阻力、更多参与者或更难的价值取舍。每次重复都要增加至少一项：规模、个人代价、信息复杂度、关系牵连、道德难题或不可逆后果。

### 3.4 反转与信息释放

反转不是把读者不知道的事实突然说出来，而是重新排列读者已经拥有的证据。合格反转至少满足：

- 事后能回溯到先前证据或规则。
- 不破坏人物知识边界和行动能力。
- 让先前行为获得新的解释，而不是单纯替换答案。
- 反转后的局面比反转前更难或更有意义。
- 反转不会一次性消费后续几十章的所有问题。

信息释放有三种成本：

1. **理解成本**：读者需要重组已有信息。
2. **情绪成本**：读者必须重新评价一个人或一段关系。
3. **行动成本**：角色知道真相后必须做出更难的选择。

只提供第一种成本、没有情绪和行动后果的“揭秘”，通常只是资料更新。

### 3.5 线性、树状和网状结构

三类结构没有高下，关键是让结构与作品承诺相匹配：

| 结构 | 适合的体验 | 主要风险 | 需要的护栏 |
| --- | --- | --- | --- |
| 线性成长 | 读者跟随一个主角跨越障碍，获得阶段性成长 | 升级循环重复，配角退化为工具 | 让成长改变关系与价值选择，而非只改变数值 |
| 树状单元 | 每个单元有相对完整问题，同时汇入长期主线 | 单元彼此无影响，主线稀释 | 每个单元至少留下人物、资源或认知变化 |
| 网状群像 | 多个角色和关系共同推动世界变化 | 视角混乱、中心承诺被分散 | 明确 POV 责任、交汇点、信息差和主线锚点 |

网状结构尤其要维护角色网络：谁与谁发生接触、关系是合作还是利用、情绪方向如何变化、哪个角色拥有改变局面的资源。研究表明，复杂且动态的社会网络能增强历史小说的叙事丰富度；工程上可以将关系图作为辅助证据，但不能用边数量代替人物质量。

## 4. 人物刻画：欲望、行动、声音与弧光

### 4.1 人物模型的最小闭环

人物卡片至少应该包含以下相互作用的元素：

```text
外在目标：他想得到什么？
内在需要：他真正需要学会什么或承认什么？
核心矛盾：两种都合理的愿望如何互相牵制？
恐惧/局限：他不能承受什么，或看不见什么？
资源/优势：他凭什么能行动？
关系压力：谁让他的选择更难？
价值底线：什么情况下会破例？
错误策略：他习惯如何解决问题，为什么会失效？
代价承受：他愿意失去什么，不愿失去什么？
弧光：哪些选择让他成为不同的人？
```

不要把“善良、冷静、聪明、坚强、腹黑”等形容词当成人物。形容词只有在具体场景里表现为偏好、误判、动作、语言和代价时才是可写的。

### 4.2 人物弧光的四种变化

人物不一定要“变好”，但必须在故事中经历可观察的变化：

- **认识变化**：对自己、他人、世界规则或过去事件的理解改变。
- **选择变化**：面对同类压力时，做出不同于早期的选择。
- **关系变化**：信任、依赖、敌意、责任或边界重新排序。
- **处境变化**：身份、资源、身体、社会位置或行动范围发生变化。

最有力的弧光往往不是“知道了正确答案”，而是人物知道代价仍然选择承担。审校时要寻找选择证据，不接受仅靠旁白宣布“他成长了”。

### 4.3 群像与人物主体性

重要配角至少要有：

1. 不依赖主角也成立的欲望。
2. 自己的关系网络与责任对象。
3. 会伤害自己或他人的错误策略。
4. 能够拒绝主角、误解主角或利用主角的行动权。
5. 与主角不同的知识边界、语言习惯和价值排序。
6. 不属于主角的日常质地，例如职业动作、生活习惯、私人承诺或独立矛盾。

“配角有自己的故事”还不够。必须检查这些故事是否会实际改变主角的选择、资源、认知或关系；否则只是旁支百科。

### 4.4 对话与声口

角色声口由多个维度共同构成：

| 维度 | 设计问题 |
| --- | --- |
| 词汇层级 | 角色常用口语、术语、典故还是沉默？ |
| 句式节奏 | 短促、迂回、完整、断裂，还是先答非所问？ |
| 信息策略 | 直说、试探、遮掩、反讽、借题发挥还是故意误导？ |
| 关注对象 | 他注意价格、天气、武器、礼法、身体反应还是他人表情？ |
| 情绪防御 | 发怒、开玩笑、讲道理、转移话题还是装作不在意？ |
| 权力位置 | 说话时能否打断别人，是否需要敬语，谁在等待对方回答？ |
| 变化边界 | 角色在不同压力下会怎样偏离平时声口？ |

声口不是给每人分配几个口头禅。删掉角色名后，读者仍能依据选择、句式和注意力方向判断说话者，才算形成差异。

### 4.5 人物刻画的场景证据

每次重要人物出场，至少优先呈现一种可见证据：

- 他如何处理一个小麻烦。
- 他在没有观众时做什么。
- 他面对弱者、敌人或熟人时是否采用不同标准。
- 他如何使用、拒绝、隐藏或赠送一件物品。
- 他在不能同时保全两件东西时选择什么。
- 他如何说出不愿承认的情绪。
- 他对环境的感受是否与其他人不同。

若人物档案里有大量背景，但正文没有行动、关系和感官证据，不能判定人物已经立体。

## 5. 感情线：从宣言转向行动与不可逆变化

### 5.1 感情线的基本原则

高质量感情不是“情绪词更多”，而是两个人的行动空间、信任结构和风险承担逐步改变。感情阶段可以采用下表作为抽象模型，但不必机械按阶段顺序：

| 阶段 | 主要问题 | 可观察证据 |
| --- | --- | --- |
| 注意 | 为什么这个人进入我的注意范围？ | 特殊观察、误会、竞争、共同处境 |
| 试探 | 我愿意暴露多少，能承受多少拒绝？ | 试探性帮助、回避、交换、边界测试 |
| 识别 | 我开始理解对方的真实代价了吗？ | 记住细节、修正判断、看见脆弱处 |
| 信赖 | 我会在没有保证时把什么交给对方？ | 交托信息、资源、背后保护、共同秘密 |
| 冲突 | 我们的欲望、责任或价值真的冲突在哪里？ | 选择分歧、误伤、撤回承诺、边界重订 |
| 承担 | 我愿意为关系承担什么不可逆代价？ | 行动牺牲、公开站队、放弃便利、共同承担后果 |
| 重建 | 关系如何在损伤后变得更真实或结束？ | 道歉、补偿、重新谈条件、接受无法恢复 |

### 5.2 具体行动、物件和重复意象

感情进展优先通过下列承载物呈现：

- 对方记住并在关键时刻使用的小信息。
- 在无人要求时提供的照料、保护、等待或让步。
- 共同承担的空间、物件、任务和风险。
- 同一个动作在不同阶段的意义变化。
- 一次拒绝或越界之后，双方如何重新协商边界。
- 关系对主线选择造成的实际影响。

同一意象重复出现时，每次至少有一项变化：拥有者变化、语境变化、人物理解变化、关系阶段变化或代价变化。单纯重复“某个物件很重要”会迅速变成装饰。

### 5.3 避免心理捷径

以下模式应作为审校信号，而不是精确词语黑名单：

- 角色刚认识就由旁白宣布深爱。
- 用一段心理总结替代多个可观察行动。
- 用误会无限拖延，而双方没有合理的沟通障碍或新选择。
- 一方永远照顾、等待和牺牲，另一方没有主体欲望。
- 感情线只在主线暂停时出现，关系变化不改变剧情。
- 冲突只靠“突然不信任”或“突然吃醋”，没有利益、认知和边界根因。

真正的修复不是再写一句更强的情话，而是补足人物行为、知识边界、关系阶段和后果。

### 5.4 非恋爱关系也适用

亲情、师徒、朋友、同僚、敌手和群体归属都遵循同一底层机制：

```text
关系期待 → 具体行动 → 对方解释 → 误差或确认 → 新边界 → 后续选择
```

因此，感情线审核不应只寻找情侣，也要观察作品中所有重要关系如何承载主题和人物成长。

## 6. 世界观：规则、制度、日常与主题

### 6.1 世界观的五层

一个可长期写作的世界至少需要形成以下层次：

1. **物理/超自然规则**：什么可以发生，什么不能发生，代价是什么。
2. **资源与技术**：力量、信息、交通、医疗、货币、生产和传播如何分配。
3. **制度与组织**：家庭、门派、官府、公司、宗教、学校、军队或平台如何运作。
4. **文化与日常**：语言、礼仪、食物、节庆、职业、禁忌、审美和地方差异。
5. **价值与冲突**：世界奖励什么、惩罚什么，哪些规则对不同人不公平。

只有第一层而没有后四层，通常是力量设定；只有文化名物而没有第一、二层，则容易成为装饰性考据。

### 6.2 规则的可内化性

读者不需要背完设定，但应能根据已出现的规则预测一部分后果。检查三件事：

- 规则是否稳定，还是每次危机都临时新增例外。
- 规则是否有成本，还是只在主角需要时提供便利。
- 规则是否会让不同阶层、职业和性格的人做出不同选择。

“合理”不等于“没有奇观”，而是奇观出现后仍能追问它的来源、代价、受益者和受害者。

### 6.3 世界观必须进入人物选择

世界细节最有效的使用方式不是介绍，而是让它改变一场戏：

- 礼法让人物不能直接说出真话，于是选择借物传意。
- 资源稀缺迫使两个人在救谁的问题上发生冲突。
- 地理和季节改变行动时间、消息速度和身体状态。
- 制度让善意必须通过手续、交换或风险才能实现。
- 超自然规则让一个看似简单的愿望产生长期代价。

如果删掉世界观专有名词，人物仍能做同样的选择，说明设定还没有成为叙事压力。

### 6.4 文化材料的使用

传统文化、地方经验和历史材料可以提供：

- 人物的价值语言和身份记忆。
- 场景的秩序、禁忌和感官质地。
- 角色之间的共同理解或误解。
- 主题的隐喻，但隐喻必须在事件中承担后果。

使用文化材料前要区分“资料正确”和“文学有效”。查证不能直接替代人物体验；资料应经过角色、时代、阶层和叙事视角的过滤。

## 7. 文风与文笔：建立可变而稳定的声音

### 7.1 文风契约的组成

建议把文风记录为一组可解释的滑杆，而不是一个作者名字：

| 维度 | 可能的范围 | 审校问题 |
| --- | --- | --- |
| POV | 第一人称、限知第三人称、多 POV 等 | 信息是否超出当前视角？ |
| 叙述距离 | 贴近身体/意识，或更远的叙述者观察 | 内心、动作和旁白是否混淆？ |
| 时间方式 | 顺叙、回忆、预示、并置 | 时间跳转是否有清楚触发和代价？ |
| 句式节奏 | 短促、舒展、断裂、复沓 | 节奏是否随场景压力变化？ |
| 词汇层级 | 口语、书面、古典、专业、地方性 | 用词是否属于人物和时代？ |
| 感官重心 | 视觉、听觉、触觉、嗅觉、身体反应 | 细节是否从 POV 的注意力产生？ |
| 比喻密度 | 低、适中、高 | 每个比喻是否增加理解或情绪？ |
| 对白比例 | 低、平衡、高 | 对白是否在做事，而不只是传递信息？ |
| 留白程度 | 直接说明到高度含蓄 | 省略处是否有足够证据可推断？ |
| 叙述态度 | 温柔、冷峻、讽刺、克制、热烈等 | 叙述者态度是否稳定又能随人物变化？ |

### 7.2 中文语言的可读性与文学性

中文长篇需要同时处理意义、音律和阅读速度：

- 句子先保证主谓关系、指代和动作清楚，再谈诗意。
- 长短句形成节奏变化，但不要把每句都切成短句制造“金句感”。
- 书面语、口语和古典语汇要有角色与场景来源，不能把典故当高级词汇库。
- 比喻要从人物此刻看见的世界生成；同一核心意象的重复必须发生意义变化。
- 具体名词、动作和身体感受比抽象情绪词更能让读者进入现场。
- 情绪高潮时可以克制，但克制必须有动作、空间或声响承载；“不说”不等于没有文本证据。
- 文学性不等于降低可读性。读者能跟上因果、视角和说话者，才有余力感受语言。

### 7.3 场景段落的微观结构

一个有效段落不必每次都完整，但通常可以在以下元素中选择两到四项形成推进：

```text
观察/感官 → 角色解释 → 身体或动作反应 → 关系反馈 → 选择/未选择
```

避免连续多个段落都采用“抽象感受 → 哲理总结 → 解释意义”的同一节奏。可以改为物件、动作、对白停顿、环境阻力和不完整的认知，让意义从读者的拼接中产生。

### 7.4 旁白总结的边界

总结有用的场景：跨越时间、压缩重复过程、建立历史视野、处理不适合逐场呈现的事实、形成叙述者的特殊声音。

总结危险的场景：

- 代替关键选择。
- 代替感情发生。
- 代替人物互相误解或理解的过程。
- 在人物没有证据时替人物下结论。
- 连续复述刚刚发生的蓝图、审核意见或章节目标。

判断方法不是禁止“他感到”“这意味着”等词，而是问：删掉总结后，读者是否仍能从行动和细节理解变化？如果不能，就需要补正文证据，而不是只删词。

### 7.5 角色声音与全书风格的关系

全书文风应统一叙事底色，但不应抹平角色差异。审校时分别判断：

1. 叙述者的稳定契约是否被遵守。
2. 当前 POV 的注意力、判断和语言是否属于该人物。
3. 不同角色在同一事件中的表达是否有可辨识差异。
4. 角色的变化是否有原因，而不是随机换腔。

## 8. 幽默、日常与烟火气

幽默不是每章必须出现的指标，而是人物、关系和处境自然产生的调节方式。常见来源包括：

- 人物认知与现实之间的错位。
- 权力关系中的礼貌、推诿、装腔和反击。
- 某个角色一贯的偏执、认真或不合时宜。
- 生活琐事与宏大目标的并置。
- 语言双关、反讽和误解，但必须符合时代与人物。
- 沉重事件后的不合时宜反应，且不取消事件的后果。

审核幽默时问：

- 删除这段，人物是否失去一个可识别的侧面？
- 笑点是否来自正在发生的处境，而不是作者插入的段子？
- 是否破坏了悲剧、严肃冲突或人物底线？
- 角色在不同关系面前是否会使用不同的幽默方式？

烟火气也不是堆食物和天气。真正的日常质地来自人物如何工作、等待、交易、照顾、争执、犯小错和处理物件；这些细节应让人物和世界更具体，并偶尔产生剧情或关系后果。

## 9. 开篇与结尾

### 9.1 开篇的任务

开篇不必把所有设定讲完，但要尽快建立：

- 一个具体且可感的现场。
- 一个正在发生或即将发生的异常/压力。
- 一个值得跟随的 POV，其欲望和处境可理解。
- 一条读者问题或承诺。
- 一种与作品相称的语言声音。

常见开篇失败不是“慢”本身，而是没有方向：大量背景说明、角色名词和世界百科在人物尚未做出选择前堆积，或者连续事件很刺激却没有核心人物和阅读承诺。

### 9.2 结尾的任务

结尾要处理的不只是最终敌人，还包括：

- 核心主题问题得到人物行动层面的回答。
- 主线承诺得到兑现或有意反转，并说明代价。
- 主角与重要配角的状态和关系有落点。
- 世界是否改变、谁承担后果、哪些问题仍可开放。
- 最后一幕的情绪与全书承诺相称，而不是只剩信息清单。

长篇常见结尾问题是前面不断扩张规模，最后只能用旁白快速概括。应在中后期逐步关闭不再服务主题的支线、回收核心意象，并把最终冲突收敛到人物最难的选择上。

## 10. 类型适配：同一底层原则的不同表现

| 类型 | 核心阅读承诺 | 重点设计 | 典型退化 |
| --- | --- | --- | --- |
| 仙侠/玄幻 | 探索未知、成长、秩序与自我超越 | 规则成本、境界意义、势力制度、天地与人间的关系 | 战力通胀、境界报表、设定替代人物 |
| 武侠/历史架空 | 江湖/政治/伦理选择与人物风骨 | 身份秩序、资源与名分、行动后果、文化语境 | 只写名场面和金句，忽略制度与普通人 |
| 都市/现实 | 熟悉生活中的欲望、关系和困境 | 职业流程、经济压力、地方经验、社会网络 | 标签化人物、方便巧合、情绪宣言替代生活细节 |
| 言情/情感 | 关系变化、理解与选择的情绪回报 | 双方主体性、边界、行动证据、阶段不可逆 | 一方工具化、误会拖延、只甜或只虐 |
| 悬疑/推理 | 追踪问题并重新理解证据 | 信息差、公平线索、动机与能力、揭示后的行动后果 | 依赖隐藏信息、反派降智、谜底与主题无关 |
| 科幻 | 新技术/制度下的人类处境与想象 | 技术约束、社会分配、伦理代价、陌生化细节 | 术语展览、科技万能、人物只是观点载体 |
| 群像/多 POV | 多个人的选择共同改变局面 | POV 责任、信息地图、交汇点、关系网络 | 视角漂移、主线失焦、配角平行自转 |

类型规则是读者合同，不是免除人物、语言和主题责任的借口。

## 10.1 高评价作品的可迁移经验

下表的“经验”是对作品机制的抽象，不是仿写指令。作品被选入是因为它们提供了不同的质量证据和叙事尺度，不能理解为单一排名。

| 作品/案例 | 评价信号与观察依据 | 可迁移机制 | 对本项目的投影 | 适用边界与反例 |
| --- | --- | --- | --- | --- |
| 《平凡的世界》 | 茅盾文学奖获奖作品；相关创作回顾记录了长期生活体验、广泛阅读和时代资料准备 | 现实逻辑不是背景装饰，而是人物资源、机会、阶层和选择的约束；群像通过共同的时代变化互相影响 | `researchNeeds`、worldview 的制度/资源层、characters 的独立欲望；D1/D2/D3/D4 审校应寻找选择与社会条件的连接 | 不要求所有作品写实、百万字或先做同等规模田野调查；幻想题材也必须让自身规则产生可预测后果 |
| 《活着》 | 余华公开谈到现实经验、题材决定叙述方式，以及让人物拥有自己的声音 | POV、人物知识和语言必须互相匹配；苦难的重量来自人物如何继续生活，不来自不断叠加灾难 | 冻结 `povCharacterId` 和知识边界；prose-reviewer 检查叙述距离、人物声口和总结是否替代经验；D2/D4/D5 | 不把悲剧、第一人称或“忍受”做成通用模板；轻喜剧、冒险或群像作品可以用完全不同的情绪合同 |
| 《三体》 | 获雨果奖；刘慈欣公开说明其长篇由多个创意组成，并强调科幻想象须建立在科学与社会现实上 | 设定先形成规则和推演空间，再把宏观后果压回人物与社会选择；主题从局面和代价中长出来，而不是靠宣讲 | worldview 保存规则、来源和代价；plot-design 维护信息释放与后果；structure-reviewer 检查规则是否可内化、反转是否有证据；D1/D2 | 不奖励更大的尺度、更多术语或更冷酷的结论；现实题材同样需要约束，但不必引入科幻设定 |
| 《长安的荔枝》 | 公开发表并有作者访谈；访谈强调小人物视角、历史细节和运输过程中的客观约束 | 把一句宏大事件拆成连续的技术、地理、制度和人际障碍；每一步都改变下一步的可行方案 | `researchNeeds` 转化为可验证事实；scene 的 `opposition/decision/outcome/cost` 记录过程链；D1/D2/D3/D5 | 不把考据数量、倒计时或职场流程当成故事质量；安静章和关系章可以用其他类型的阻力 |
| 《诡秘之主》 | 中国作协发布的网络文学发展报告记录了其连载期的阅读、评论、月票和社群反馈规模 | 连载作品需要可持续的读者问题、阶段回报和长期谜团；社区反馈可以作为观测信号，但不能替代作者的事实真源 | narrative ledger 管理 promise 生命周期；chapter memory 保存截止点；learning 可统计读者反馈与正文问题的关系，但不把热度写入质量门；D2/D3 | 评论数、打赏和榜单只能证明参与度，不能证明每个情节都优秀；不允许读者反馈绕过 canon、知识边界或正式审批 |
| 2024 年中国网络文学影响力榜案例 | 中国作协网络文学中心从有效申报项目中评出网络小说、IP 影响、海外传播和新人榜；报道特别提到突破爽文法则、现实主义品格、地域经验和独特世界观 | 当前网文精品化正在同时扩大题材、现实关切和类型表达；“类型回报”与“人物处境”可以并存 | Foundation 的读者承诺同时描述类型回报和情感/认知价值；reviewer 允许按章节功能判断，不要求每章都爽或每章都现实主义 | 榜单是机构评审与影响力信号，不是普遍审美的最终裁决；不能因入榜作品的共性就要求所有作品加入现实议题或破类型套路 |

这些案例共同支持六条更稳健的结论：

1. **先建立可感的约束，再让人物在约束中选择。** 约束可以是时代、身体、制度、技术、关系或资源，不必都是战斗冲突。
2. **把宏观设定压回具体生活。** 读者相信世界，不是因为读到了更多名词，而是因为规则改变了人的工作、等待、交易、身体和关系。
3. **人物声音和 POV 是信息控制器。** 叙述方式应由人物的知识、身份、经验和注意力决定，不能由模型的默认文风决定。
4. **长篇的推进单位是状态与意义的变化。** 新事件只有在改变资源、关系、认知、承诺、风险或后续选择时才形成可追踪的推进。
5. **连载回报需要多尺度分布。** 单章可以给局部解决、情绪确认、认知改写或新问题；故事弧再负责更大的兑现，避免每章重复同一种刺激。
6. **质量改进必须同时看文本和系统证据。** 评分、榜单、评论和模型自评只能触发调查；最终要回到正文 excerpt、事实/状态、跨章回归和修订后的局部副作用。

### 10.2 作品案例的通用审校问题

对任何新案例，至少回答以下问题，再决定是否进入 prompt、schema 或 skill：

- 作品效果由什么具体机制产生，而不是由哪个作者名字保证？
- 该机制影响 D1 世界观、D2 故事性、D3 群像、D4 感情线、D5 幽默中的哪些维度？
- 它适合哪些类型、POV 和章节功能？在哪些情况下会变成拖沓、说教、信息倾倒或模仿？
- 是否能在正文中找到逐字证据，或在结构化状态中找到可追踪证据？
- 如何验证原失败场景和一个题材、关系或章节功能明显不同的反例都没有被误伤？

## 11. 面向 novel-v2 的创作闭环

### 11.1 推荐的数据流

```text
创作简报
  → Foundation 五阶段：定位、架构、人物、世界观、剧情设计
  → Foundation review：检查全书承诺、事实边界、结构可持续性和收束方向
  → Story Arc：阶段目标、因果、人物弧、剧情线、伏笔和关系窗口
  → Chapter Planning Context + Memory：编译当前执行合同和截止点事实
  → Preflight：确认事实、状态、承诺、知识边界和文风版本
  → Draft：按场景写正文，不回显指令和蓝图
  → 三类 Reviewer：structure、character、prose
  → Revision：按证据修订，检查局部退化和事实漂移
  → Manuscript Approval → Fact Extraction → Fact Approval
  → Commit + enrichCharacters：提交正文、版本、章节记忆并更新人物
  → Learning：从重复问题归因到底层机制，形成候选改进并回归验证
```

正式章节审校和已定稿章节重审都复用 `chapterReviewWorkflow` 的 `review → revise → manuscriptApproval → extractFacts → approveFacts → commit → enrichCharacters` 链路；不另起离线修订流程。章节蓝图和场景字段的当前活动契约以 `quality-standard.md` 与 `workflow-map.md` 为准，本文只总结其文学责任。

### 11.2 每个阶段的文学责任

| 阶段 | 必须保证 | 不要做成 |
| --- | --- | --- |
| Foundation | 作品承诺、主题问题、世界压力、主角矛盾、群像方向 | 角色名和设定名词生成器 |
| Story Arc | 因果弧、阶段转变、线路关系、伏笔窗口、出口状态 | 章节标题列表 |
| Chapter Blueprint | 本章功能、起始/结束状态、人物选择和边界 | 正文待办清单或固定字数计划 |
| Preflight | 当前截止点事实、知识边界、活跃承诺、文风版本 | 全书资料倾倒 |
| Draft | 视角内的具体经验、动作、对白和情绪变化 | 蓝图复述、审核说明或设定百科 |
| Foundation review | 检查全书承诺、事实边界、结构可持续性和收束方向 | 用章节偏好替代全书契约，或把模型分数当成批准依据 |
| Review | 证据化识别问题、区分适用性与缺口、保护作者意图 | 只给总分、固定短语扫描 |
| Revision | 改善目标问题，保留事实、声口、人物主体性和后续空间 | 重新写成审稿人喜欢的另一部小说 |
| Fact / Commit | 只提交已批准正文产生的事实和记忆 | 把大纲意图提前写成事实 |
| Learning | 识别根因、受影响输入类和边界，跨场景回归 | 为某一章节加禁词或特判 |

### 11.3 Prompt 与结构化输出原则

- 能用 schema 表达的内容优先结构化：章节功能、状态变化、POV、问题证据、事实来源、伏笔身份和修订结果。
- 提示词先写一般原则，再给跨题材、跨人物、跨章节功能的示例。
- 例子必须说明“为什么有效”和“边界在哪里”，不能让示例成为隐藏产品契约。
- 元注释、指令回显、代码围栏和审核说明应在结构化输出层或通用结构启发式层治理，而不是添加精确短语黑名单。
- 生成请求提交一份完整、连贯的 instruction；不要依赖无上下文 Web API 的远端会话拼接多段内容。
- 正文生成、审校和修订的上下文都必须带来源、叙事截止点和版本指纹。
- Story Arc review/revision 也必须把 planning、截止点账本、开放元素和机制反馈拆成可审计 sections；最终 instruction 仍保持完整连贯，不依赖远端会话拼接上下文。
- 长篇账本要分层进入上下文：定稿事实、当前状态和必要 facet 是硬边界；开放伏笔与承诺保留规范 ID、窗口和来源，但只作为可排序候选，不自动变成当前章节的待办清单。故事弧规划应接收最近定稿章节形成的机制反馈（机制、影响输入类和边界），而不是只重复问题表面。
- 章节修订中，已批准/episodic 事实、作者边界和章节执行合同保持 required；背景记忆和 narrative rhythm 属于 normal/soft。`sourceArtifactId` 只说明来源，不代表内容重复。
- 人物独立行动契约至少包含 desire、choice、cost 和 knowledgeBoundary；旧历史可保留，但当前 Foundation 生成与全书架构审计必须报告缺失字段。
- Skill execution point 漂移必须可诊断；未知点不得静默过滤，实际 resolution 应阻断并指出 skill、version 和失效点。
- 兑现关系优先使用 fact extraction 看到的精确叙事元素 ID；旧输出只有在唯一候选时才允许关键词/承诺者回退，多候选保持开放。可追溯的“未兑现”比错误的“已兑现”更适合后续规划和人工复核。

## 12. 可执行审校矩阵

### 12.1 D1 世界观

| ID | 判据 | 证据问题 |
| --- | --- | --- |
| W1 | 规则可内化 | 随机抽取规则，读者能否推导后果？ |
| W2 | 设定承载主题 | 核心设定是否改变人物选择并承载主题问题？ |
| W3 | 跨章一致 | 规则、资源成本和制度反应是否漂移？ |
| W4 | 世界独立质地 | 世界是否在主角不需要时仍有生活、利益和变化？ |
| W5 | 文化材料有来源 | 词语、制度、习俗和历史是否符合时代/地域/角色视角？ |

### 12.2 D2 故事性

| ID | 判据 | 证据问题 |
| --- | --- | --- |
| S1 | 章节功能成立 | 本章实际完成了什么变化？ |
| S2 | 因果由人物驱动 | 转折能否追溯到欲望、选择和局限？ |
| S3 | 伏笔可回溯 | 兑现是否有来源证据，是否增加新意义？ |
| S4 | 节奏匹配功能 | 安静章、行动章、高潮章是否采用相称的展开深度？ |
| S5 | 线路可管理 | 活跃线是否有状态、交汇、退出和兑现计划？ |
| S6 | 回报不是机械 | 读者获得的是解决、成长、理解或情绪确认，而非固定套路？ |

### 12.3 D3 群像

| ID | 判据 | 证据问题 |
| --- | --- | --- |
| E1 | 配角有独立欲望 | 配角是否为自己的目标行动？ |
| E2 | 角色声部可区分 | 遮住名字后能否根据语言、注意力和选择识别？ |
| E3 | 弧光可观察 | 角色是否在认识、选择、关系或处境上改变？ |
| E4 | 关系网络有动态 | 合作、利用、竞争、责任和背叛是否变化？ |
| E5 | 主体性不被主角吞没 | 配角能否拒绝、误解、利用或改变主角？ |

### 12.4 D4 感情线

| ID | 判据 | 证据问题 |
| --- | --- | --- |
| R1 | 行动承载 | 进展是否由行动、物件、边界和共同后果呈现？ |
| R2 | 阶段转变 | 是否有可指认且有证据的关系阶段变化？ |
| R3 | 与主线交织 | 关系变化是否改变主线选择或被主线真正影响？ |
| R4 | 双方有主体性 | 双方是否都有欲望、局限、行动和成长？ |
| R5 | 复杂度 | 是否存在责任、自由、信任、伤害和修复的张力？ |

### 12.5 D5 幽默

| ID | 判据 | 证据问题 |
| --- | --- | --- |
| H1 | 来自人物与处境 | 删除笑点后，人物或关系是否失去信息？ |
| H2 | 时代/类型契合 | 语言和参照物是否属于世界？ |
| H3 | 调节而非打断 | 幽默是否保留了严肃事件的后果？ |
| H4 | 角色一致 | 该角色在此压力下为什么会这样幽默？ |

### 12.6 跨维度审校

- **视角**：谁看到、谁知道、谁误解，叙述是否泄漏不该出现的信息？
- **连续性**：人物状态、伤势、资源、地理、时间、关系和知识是否一致？
- **具体性**：情绪和主题是否有行动、环境、物件和身体反应承载？
- **声音**：叙述者、POV 人物和对白是否各自成立？
- **原创性**：是否出现对已有文本的直译、套句、过度可识别模仿或泛化 AI 套话？
- **后果**：本章结束后什么无法无痕恢复？如果没有不可逆变化，是否有明确的静态章节功能？
- **回收**：是否引入了无法管理的承诺、人物或剧情线？

## 13. 常见退化模式：从症状追到根因

| 表面症状 | 可能的共享根因 | 应优先修复的层 | 不建议的补丁 |
| --- | --- | --- | --- |
| 正文像大纲或审核报告 | 生成合同没有区分“规划资料”和“正文输出” | stage schema、prompt contract、输出净化 | 加一串禁止回显的精确短语 |
| 章节推进很快但没有重量 | 把事件数量当成故事推进，缺少选择和余波 | blueprint 的状态变化与 reviewer 证据 | 只要求每章更多冲突 |
| 章节拖沓像流水账 | 场景没有目标/阻力/选择，日常没有变化 | scene plan 与 plot reviewer | 强行提高字数或每章加高潮 |
| 金句密集但人物空 | 语言脱离 POV 和行动，主题没有进入选择 | style/character contract | 继续增加诗词、比喻和名言 |
| 感情线靠宣言 | 行动证据、阶段和边界没有建模 | 关系状态、人物行动证据和 reviewer | 禁止若干心理词 |
| 配角都像主角 | 角色只从主角需求生成，没有独立欲望与关系图 | character model、ensemble review | 给每人加一个口头禅 |
| 世界观像百科 | 设定没有成本和制度压力 | world rules、context projection | 再增加更多设定条目 |
| 伏笔越来越多却不回收 | promise 没有身份、窗口、证据和生命周期 | narrative ledger、memory/commit | 让模型“记住所有伏笔” |
| 反转靠新信息 | 规划没有铺设证据或人物行动链 | plot planning、information map | 让反派解释更多 |
| 长篇中后期重复升级 | 同一奖励/危机没有改变意义和代价 | arc strategy、fatigue/repetition review | 调高爽点密度 |
| 修订总分上升但正文变差 | 接受逻辑没有局部退化上限或证据路径 | revision policy、candidate comparison | 只追求总分最大化 |
| 多 POV 让读者迷路 | 缺少 POV 责任、信息地图和交汇规则 | arc/blueprint schema | 每章开头重复角色介绍 |

根因分析必须同时记录：观察症状、失败工作流层、底层机制、受影响输入类、行为边界和回归风险。原失败场景之外，至少验证一个题材、人物关系、章节功能或 POV 明显不同的反例。

### 14.1 GitHub 项目筛选标准

后续继续搜寻仓库时，优先检查：

1. 是否有真实的结构化产物和失败处理，而不是只有一个“生成全文”按钮。
2. 是否区分创作契约、事实、候选输出、摘要和正文。
3. 是否支持局部重跑、版本、来源、人工审批和回滚。
4. 是否有跨章节一致性、角色状态、伏笔/承诺或信息截止点的处理。
5. 是否有测试、示例产物和可复现实验，而不是只有 README 宣称的质量分数。
6. 是否遵守许可证、第三方模型条款和用户文本隐私边界。
7. 是否把风格抽象成通用属性，而不是鼓励复制在世作者。

## 15. 推荐的项目落地顺序

### P0：参考资料与词汇统一

- 将本文作为项目级参考文档，不直接注入全部 prompt。
- 以 `quality-standard.md`、`workflow-map.md`、`pipeline-audit.md` 和 `prompt-skill-audit.md` 中的正式术语为准。
- 对每个原则建立“设计文档 → schema 字段 → prompt 投影 → reviewer 证据 → 回归样本”的追踪关系。

### P1：规划层

- 完善创作简报中读者承诺、主题问题、主角矛盾、情感契约和结局包络的说明。
- 让故事弧保存每条剧情线的推动者、当前问题、交汇方式、出口状态和兑现窗口。
- 让章节蓝图遵守当前活动字段：`narrativeFunction`、`povCharacterId`、`stateTransition`、`scenes`、`continuityConstraints` 和 `unresolvedAtClose`；把感官锚点、信息差等文学材料放在场景执行上下文中，不另造过时的章节硬字段。

### P2：人物与关系层

- 为重要角色保存独立欲望、错误策略、关系压力、知识边界和可观察弧光。
- 为重要关系保存阶段、行动证据、边界、冲突和不可逆节点。
- 在 reviewer 中增加角色声部盲测和主体性证据，而不是只检查角色字段是否非空。

### P3：正文与审校层

- 把“正文不得回显元说明”落实在结构化输出和通用净化层。
- 将 W/S/E/R/H 维度映射到可引用的正文证据，允许 `not-applicable`，不因安静章节缺少动作或幽默误杀。
- 修订接受逻辑同时守护整体改善、局部退化上限、事实稳定和人物声音。

### P4：长篇回归层

- 建立跨题材、跨 POV、跨章节功能的回归集。
- Craft Rule 的异构反例必须由历史蓝图派生 ScenarioProfile 证明差异，不能只选择两个不同章节 ID。
- 统计伏笔生命周期、剧情线活跃时长、角色声部混淆、关系状态回退、重复意象和修订策略重复。
- 在 skill/prompt promote 后真实重跑失败场景，再验证一个实质不同的反例。

### 16.3 本项目已有作品细读说明

- 《雪中悍刀行》：作为 C 级文本细读案例，重点观察江湖与庙堂如何相互影响、配角如何拥有独立弧光、武戏如何承载身份与价值冲突，以及短句、留白和豪情之间的节奏关系；同时记录后期战力膨胀、支线拖长和收束压力作为反面样本。
- 《剑来》：作为 C 级文本细读案例，重点观察庞大世界、文化思想、人物声口、意象复现和慢热节奏如何共同形成文明史诗感；同时记录过度哲思、叙事停滞、重复说明和长篇记忆负担。
- 《我在风花雪月里等你》：作为项目已有文本细读案例，重点观察都市情感中的行动细节、复杂心理、现实压力和第一人称叙述如何累积关系重量。由于本次检索未找到同等可靠的作者创作谈，不把它当作外部权威方法来源；同时记录后期拖沓、人物选择争议和结尾收束作为反例。

对三部作品的共同结论不是“组合三种作者风格”，而是：人物选择产生剧情，剧情改变关系和认知，世界规则制造真实代价，语言把这一切转化为可感经验；长篇通过伏笔、意象、回声和状态账本保持跨章节的意义累积。

## 17. 维护规则

当新增创作经验时，必须同时补充：

1. 经验来源与证据级别。
2. 可迁移的机制，而不是具体角色、标题、句子或章节的规则。
3. 适用边界和不适用章节功能。
4. 对现有 D1 世界观、D2 故事性、D3 群像、D4 感情线、D5 幽默的映射。
5. 需要新增或修改的 schema、prompt、reviewer、validator 或学习闭环。
6. 原失败场景和至少一个实质不同反例的回归证据。
