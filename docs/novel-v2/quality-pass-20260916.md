## 目标重述（一元判据）
高质量网文正文 = 具体的人在现场活着 + 读者想往下读。AI 味是未达此标的症状，不是独立靶子。
声音多样性合法（ch11 的快与 ch88 的慢可以并存）——凡以"向某声部靠拢"为由的改动一律驳回；
凡以"这段是概述不是现场/这句是套话不是形象/这一章没有人跟别人打交道"为由的改动才合格。

## 三条线（串行纪律不变，一章一 run）
### L1 编排端防复发（治根，最优先，改动零风险）
- 弧蓝图 phases/chapterHints 强制"对手戏配额"：每弧≥1/3 章有非主角意志驱动的事件；
  章指令模板加"≥2 段活对白且对白推进处境（对白复述功能由 e2e2b90 承接）"。
- 落点：SKILL 0b 标准件追加⑦ + 生成面 story-arc prompt 检验是否需要机制项（评估后定）。
### L2 现场化改写（治章，逐章手术）
- 对象分级：A=梗概章（ch25 型：场景未打开）；B=静默章（85/109/111/113：零对白且处境推进为零）——
  B 类先诊断"静是本章功能"（如 111 全程以笔声对话）还是"静是产能妥协"，只有后者动刀，
  动刀方式是加"对手戏事件"而非硬塞对白。
- 手术通道：targeted 加料不可靠（修订动词分界）→ 现场化一律走"新素材重出"（带对手戏的具体事件进场，
  重出指令含在场锁+事件合同）；纯删/逐字替换走 targeted。
### L3 tic 减量（治句，最后做，只做删换不做风格迁移）
- 沿用 v1 批1 点名清单（15 章）与预算：对比句≤2/息计时≤2/层语清零/身体讯族≤2 轮换/格言收梢隔章一次。
- 明喻预算改正：明喻≤1 + 暗喻不限。
